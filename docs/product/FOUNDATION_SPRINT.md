# Foundation Sprint

## Objetivo
Preparar el primer incremento funcional de Yarvis: Yarvis Inbox + Case Flow.

---

## Alcance
- recepción manual de archivos y texto;
- clasificación sugerida o manual;
- asociación a Caso y expediente;
- actualización de checklist;
- evaluación de etapa;
- creación de siguiente acción;
- auditoría.

---

## Casos de demostración
- Expediente CFE residencial.
- Alta NetPay.

---

## Interfaces mínimas
- Bandeja de entrada.
- Confirmación de clasificación.
- Detalle del Caso.
- Checklist.
- Documentos.
- Siguiente acción.
- Bitácora.

---

## Criterios de aceptación
- Se puede crear una organización.
- Se puede crear un actor o persona.
- Se puede crear un Caso de tipo CFE o NetPay.
- Se puede subir un documento.
- Se puede clasificar y asociar el documento.
- Se puede actualizar el checklist.
- Se puede generar una siguiente acción.
- Se puede consultar la bitácora.
