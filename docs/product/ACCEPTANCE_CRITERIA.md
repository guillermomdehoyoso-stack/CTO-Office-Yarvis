# Acceptance Criteria

## Foundation Sprint
1. Se puede crear una organización.
2. Se puede crear una persona.
3. Se puede crear un Caso de tipo Expediente CFE o Alta NetPay.
4. Se puede cargar un archivo.
5. Se puede clasificar y asociar el archivo.
6. Se puede marcar un requisito como recibido.
7. Se actualiza el avance del checklist.
8. Se genera una siguiente acción.
9. Se consulta la bitácora.
