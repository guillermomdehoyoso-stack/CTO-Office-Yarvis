# ADR-006: Yarvis Inbox como primer bloque funcional

- Status: Accepted
- Date: 2026-07-10

## Context
El primer valor operativo se obtiene al recibir información, estructurarla y avanzar un Caso con trazabilidad.

## Decision
El primer incremento funcional será Yarvis Inbox + Case Flow, con carga manual inicial de archivos y texto.

## Consequences
- El proyecto empieza con un flujo completo de extremo a extremo.
- Se prioriza la capacidad operativa sobre la generación de interfaces complejas.
- La arquitectura debe sostener entrada, clasificación, asociación, checklist, estado, acción y auditoría.
