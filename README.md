# EF CTO Office

Base de conocimiento estratégica para arquitectura, ingeniería, producto, investigación y toma de decisiones tecnológicas de Energía Fotónica.

## Estructura

- docs/vision: visión tecnológica y North Star.
- docs/engineering: forma oficial de construir software.
- docs/architecture: patrones, context maps y evolución de dominios.
- docs/research: radar tecnológico e ideas.
- docs/product: visión de producto y roadmap.
- docs/templates: plantillas reutilizables.
- docs/standards: estándares internos.
- docs/adr: decisiones arquitectónicas reutilizables.

## Principio central

Modelar primero el dominio, después la arquitectura y finalmente el código.
